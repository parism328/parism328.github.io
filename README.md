# Paris Myers

Personal academic website, published with GitHub Pages at https://parism328.github.io/.

Edit `index.html` to update the biography, news, and projects. Edit `styles.css` to change the design. GitHub Pages publishes the `main` branch from the repository root.

The initial biography and project descriptions are based on the three MIT articles linked on the website.
